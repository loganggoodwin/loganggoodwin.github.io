What I built

I created a 91-page company training manual for North Star Software Developers. The manual covers the full defensive workflow: traffic analysis, packet capturing, firewall rule creation, network segmentation, blocking/allowing/filtering traffic, intrusion detection and prevention, vulnerability assessment, network assessment, auditing, log collection, SIEM correlation, and a summary of approved tools.

I also created an interactive HTML training companion called NSSD Cyber Defense Mission. It turns the manual into a plain-language training experience with sections for the mission scenario, security layers, incident response flow, approved tools, glossary terms, and quiz-style reinforcement.

Why I built it

The purpose was to show how network security documentation should support real business needs after a compromise. The scenario required more than defining tools. It required explaining how packet captures, firewall records, IDS/IPS alerts, vulnerability findings, endpoint logs, and SIEM correlation work together during investigation, mitigation, and response.

Instructor feedback highlights

The feedback emphasized that the manual combined technical explanations with structured procedures and could serve as a practical starting point for IT employees. It also called out the mature use of layered evidence across packet captures, firewall records, IDPS alerts, vulnerability findings, endpoint logs, and SIEM correlation.

  • Strong connection to NSSD’s server compromise, sensitive information, software-development operations, and business priorities.
  • Practical structure for capturing traffic, evaluating alerts, configuring controls, assessing vulnerabilities, and documenting security activity.
  • Clear risk-based prioritization across mitigation, incident response, and vulnerability assessment.
  • Remaining improvement areas were presentation-level polish: reducing repetition, improving figure numbering, captions, annotations, and screenshot spacing.

Interactive training companion

The HTML version reframes the manual for nontechnical and mixed technical audiences. It uses plain-language analogies, clickable security-layer cards, a response-flow model, an approved-tools table, glossary terms, checklist progress, and quiz interactions.
