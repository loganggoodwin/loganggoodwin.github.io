# LoganGoodwin.com Brand Redesign

## Core architecture

- **LoganGoodwin.com** is the official personal brand hub.
- **Frontline Publishing** remains the complete commercial catalog for books, audiobooks, and story media.
- **Technology & Cybersecurity** is a prominent professional section without controlling the creative homepage.

## New primary navigation

Home · About · Books · Music · Commentary · Technology · Media · Contact

## New files

- `brand.css` — primary design system for the redesigned public-facing pages
- `brand.js` — responsive navigation, reveal effects, current year, and contact-form handling
- `images/logan-goodwin-brand-banner.webp` — optimized desktop hero
- `images/logan-goodwin-brand-mobile.webp` — mobile hero crop
- `images/logan-goodwin-og.jpg` — social sharing image

## Preserved content

The original project library, cybersecurity case studies, PDFs, interactive labs, audio files, resumes, certificates, CNAME, and GitHub Pages configuration remain included. Existing technical pages retain their original layouts with the color palette shifted toward the new navy-and-gold brand.

## Deployment

Upload the contents of this folder to the root of the existing GitHub Pages repository. Do not upload the enclosing folder itself. Preserve `CNAME` and `.nojekyll`.
